# ConnectCall project manifest

This package contains the application source, Android/iOS application-specific native files, Firebase configuration templates, Firestore rules/indexes, optional Node backend, tests, documentation, and the UI preview.

The Flutter platform wrapper and Gradle wrapper are generated with `flutter create .` on the developer machine so they match that machine's installed stable Flutter SDK.

Calling provider: ZEGOCLOUD Call Kit + Signaling Plugin.
ZEGOCLOUD AppID configured by default: 503220443.
ZEGOCLOUD AppSign: supplied at build/run time with `--dart-define=ZEGO_APP_SIGN=...` and never committed.
Firebase values: supplied at build/run time with `--dart-define` and never committed.
