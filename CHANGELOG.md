# Changelog

## 1.0.0

- ConnectCall Flutter internship implementation.
- ZEGOCLOUD Call Kit + Signaling Plugin for audio/video calling and invitations.
- Firebase Authentication, Firestore, and Firebase Cloud Messaging integration.
- Riverpod state management.
- One-to-one audio/video calls, incoming/outgoing flows, missed/busy/rejected/failed/disconnected statuses.
- Call history, online presence, block users, favorites, group-call selection, screen-sharing-capable call UI, network-aware guards, dark mode, permissions and error states.
- Optional Node.js backend for health checks and Firebase Admin notification delivery.
