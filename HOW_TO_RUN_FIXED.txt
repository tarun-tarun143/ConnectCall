CONNECTCALL — FIXED PROJECT

1. Install Flutter stable (Dart 3.5+ compatible).
2. Open this folder in Android Studio / VS Code.
3. Run:
   flutter create .
   flutter pub get
   flutter analyze
   flutter test

4. Run with Firebase + ZEGO values:
   flutter run ^
     --dart-define=ZEGO_APP_ID=503220443 ^
     --dart-define=ZEGO_APP_SIGN="YOUR_APPSIGN" ^
     --dart-define=FIREBASE_API_KEY="YOUR_FIREBASE_API_KEY" ^
     --dart-define=FIREBASE_APP_ID="YOUR_FIREBASE_APP_ID" ^
     --dart-define=FIREBASE_MESSAGING_SENDER_ID="YOUR_SENDER_ID" ^
     --dart-define=FIREBASE_PROJECT_ID="YOUR_PROJECT_ID" ^
     --dart-define=FIREBASE_STORAGE_BUCKET="YOUR_BUCKET"

Android Studio Terminal can also use the same dart-define flags on one line.

Important:
- Firebase configuration is intentionally passed through dart-define; no secret/config file is committed.
- ZEGO AppSign is required for calling. ServerSecret must never be placed in Flutter code.
- Firebase Storage is not used by this project. Profile images use a URL field only.
- The supplied environment did not contain the Flutter SDK, so `flutter analyze` and `flutter test` could not be executed inside this repair environment. The source/dependency/API consistency was checked statically, and the ZEGO APIs were checked against the 4.24.4 package API documentation.
