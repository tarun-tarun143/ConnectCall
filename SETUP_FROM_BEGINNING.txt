STEP 0 — BACK UP THE CURRENT PROJECT
--------------------------------------
From CMD:

F:
cd \
mkdir connect_call_backup
xcopy /E /I /Y connect_call connect_call_backup

(If the backup folder already exists, choose another name.)

STEP 1 — EXTRACT THIS ZIP
--------------------------
Put connect_call_final_source.zip in F:\

Then:

tar -xf F:\connect_call_final_source.zip -C F:\connect_call_final_source

If the destination does not exist, create it first:

mkdir F:\connect_call_final_source

STEP 2 — COPY ONLY THE CLEAN SOURCE
------------------------------------

xcopy /E /I /Y F:\connect_call_final_source\lib F:\connect_call\lib
copy /Y F:\connect_call_final_source\pubspec.yaml F:\connect_call\pubspec.yaml
copy /Y F:\connect_call_final_source\android\app\src\main\AndroidManifest.xml F:\connect_call\android\app\src\main\AndroidManifest.xml

STEP 3 — VERIFY FIREBASE FILE
------------------------------
Make sure this still exists:

F:\connect_call\lib\firebase_options.dart

Do not delete it.

STEP 4 — VERIFY ZEGO CREDENTIAL FILE
-------------------------------------
Make sure your real credentials are still in:

F:\connect_call\lib\core\constants\app_config.dart

Do not paste your AppSign into public GitHub.

STEP 5 — GET PACKAGES
----------------------

cd /d F:\connect_call
flutter clean
flutter pub get

STEP 6 — ANALYZE BEFORE BUILDING
---------------------------------

flutter analyze

Expected:
  No issues found!

Do not continue if there are analyzer errors.

STEP 7 — BUILD DEBUG APK
-------------------------

flutter build apk --debug

APK:
  F:\connect_call\build\app\outputs\flutter-apk\app-debug.apk

STEP 8 — START EMULATOR (OPTIONAL)
-----------------------------------

emulator -list-avds
emulator -avd ConnectCall_API_35 -no-snapshot

Wait until the Android home screen is fully visible.

Then:

adb devices
adb shell getprop sys.boot_completed

The second command should return 1.

STEP 9 — INSTALL APK
---------------------

adb install -r "F:\connect_call\build\app\outputs\flutter-apk\app-debug.apk"

STEP 10 — LAUNCH
-----------------

adb shell monkey -p com.tarun.d.connect_call 1

STEP 11 — TWO-PHONE CALL TEST
------------------------------

PHONE A:
  Register account A
  Log in

PHONE B:
  Register account B
  Log in

Both phones must be online and logged into ConnectCall.

Then test:
  Audio → incoming → accept → speak → mute → unmute → speaker → end
  Video → incoming → accept → local preview → remote video
        → mute → camera off/on → switch camera → end

Check Call History after every test.

IMPORTANT
---------
The assignment requires real 1-to-1 calling, incoming calls, call controls,
permissions and call history. The UI alone is not sufficient.

If `flutter analyze` is clean but a call fails at runtime, capture the exact
runtime message/log. Do not randomly change package versions or Gradle files.
